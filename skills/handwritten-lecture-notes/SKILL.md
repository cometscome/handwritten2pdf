# 手書き講義ノートの教材化

手書きの講義の筋道を保ち、学生が講義後に自分で読める教材へ整える。
原本の内容、訂正、説明の補充を追跡できるようにし、図は編集可能なTikZソースを基本とする。

## 依頼の範囲を決める

- **教材化**：原本を読み取り、説明・式・図を組み直してLaTeXとPDFを作る。
- **照合・検証**：原本と既存教材を比較して指摘をまとめる。修正も依頼されている場合に反映する。
- **改訂**：指定箇所を更新し、関連する図、参照、解答、配布版への影響を確認する。
- **図の清書**：指定図をTikZ化し、原本と本文に照合する。図だけの依頼で全文を書き直さない。

依頼、既存原稿、作業記録から次を把握する。推定可能な項目は合理的な既定値で進め、意味を決められない点だけ確認する。

| 項目 | 扱い |
|---|---|
| 科目・言語・対象学生・既習事項 | 科目名だけから学年や履修済み内容を決めない。既存情報がなければ原本の水準を出発点にする |
| 原本と編集元 | 複数版の新旧、主資料と参考資料、手書きページとPDF通算ページを区別する |
| 編集の程度 | 配布教材化は説明を補う。逐語転記の依頼では表現を勝手に展開しない |
| 構成・記号 | 原本の順序と既存の合意を基本にする。既に合意した変更を原本に機械的に戻さない |
| 出力 | 既存形式を優先。新規なら編集可能なTeXとPDF。章別版・解答・補論は依頼に応じる |

科目名、年度、教員名、単位系、章数、問題数、特定の絶対パスをスキル共通の固定値にしない。
講義ごとの設定・判断・未確定事項は講義側の原稿コメントや短い作業記録に置く。

## 原本を読む・教材へ整える

詳細は [原本照合と教材編集](references/editorial-verification.md) を読む。

1. 対象ページを画像として確認する。OCRは位置探し・下書きの補助とし、数式、添字、矢印、図中ラベルは原画像と照合する。
2. 原本のページと教材の節・式・図の対応を残す。長い原本は章などのまとまりに分け、確認済み範囲を記録する。
3. 判読が曖昧なら拡大し、前後・定義・単位を調べる。それでも未確定なら候補と影響を示し、推測を確定した転記にしない。
4. 板書の短い語句を、動機、定義、計算の目的、途中の論理、結果の解釈がつながる文章へ展開する。要約で導出や例を落とさない。
5. 原本の誤記、転記ミス、記号変更、補足、構成変更を区別する。誤りと判断する前に元の定義と文脈を確かめる。
6. 数式・説明を検証する。中心的な導出や問題の解答は再計算し、適用条件や近似を確認する。文章の読みやすさの検査を内容の正しさの検証と取り違えない。

## 図をTikZで作る

作図前に [TikZ作図と検証](references/tikz-figures.md) を読む。

- 幾何図、概念図、座標軸、ベクトル、模式図はTikZを第一候補にする。数値グラフには必要に応じてPGFPlots、回路にはCircuitikZなどを選ぶ。
- 原本の図が伝える関係を復元し、本文・式と記号、向き、境界、角度、単位を合わせる。
- 新たに補う図には説明上の目的を持たせる。写真・実験画像・データを不正確な模式図へ置き換えない。
- 図のソースを納品物に含める。ラスタ化した図だけを残さない。
- コンパイル後は実際の配置と印刷相当の大きさで確認する。文字の衝突だけでなく、図の意味が正しいかを見る。

## 組版と出力

[LaTeXのビルドと配布版](references/latex-delivery.md) を読む。
新規の日本語教材では、必要に応じて [LuaLaTeXテンプレート](assets/lecture-notes-ja.tex) をコピーして使う。
テンプレートの微分の説明・図は動作例なので、対象講義の内容に置き換える。既存原稿にテンプレートを強制しない。

- 編集元を明確にし、章別版・結合版はそこから生成する。生成物を別々に手修正しない。
- エラー・未解決参照・欠落文字・はみ出しを調べ、PDFを画像にして視覚確認する。
- 新規教材は全ページを点検する。局所改訂では変更ページと改ページ・参照の影響範囲を点検する。全体を確認していないなら、その範囲を報告する。

## 完了時に残すもの

依頼に応じたTeX、図のソース、PDFと、原本対応・重要な訂正・補足・未確定事項の短い記録を残す。
成果物の場所、変更の要点、実施した検証と対象範囲、残る問題を簡潔に報告する。
「全ページを見た」「全数式を照合した」「全問を検算した」はそれぞれ実施した場合だけ記す。
ビルド成功を、内容の正しさや原本の完全収録の証明としない。
