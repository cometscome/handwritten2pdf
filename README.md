# handwritten2pdf

**バージョン：0.1 — 実験的プロジェクト（Experimental）**

手書き講義ノートのPDF・画像を、学生が読めるLaTeX・PDF教材に整えるためのCodex用スキルです。原本との照合、説明の補充、数式の検証、TikZによる作図、PDFの組版確認までの作業手順をまとめています。

> このプロジェクトは実験的なものです。現在のバージョンは **0.1** で、手順や構成は今後変更する可能性があります。手書きの判読、数式、補足説明、図の正しさを保証するものではありません。生成した教材は、原本と照合し、内容とレイアウトを確認してから利用してください。

## できること

- 手書き原本のページと教材の節・式・図を対応づける。
- 講義の流れを保ちながら、板書で省略された動機や途中の説明を補う。
- 原本の誤記、転記ミス、記号変更、追加説明を区別して記録する。
- 図をTikZで作成し、本文との記号・向き・幾何関係を照合する。
- 編集可能なTeXとPDFを作成し、出力後の見た目を確認する。
- 既存教材との照合や、指定箇所だけの改訂にも利用する。

科目名・年度・教員名を固定せず、他の科目でも使えるようにしています。これまでの試用は日本語の電磁気学講義ノートが中心で、幅広い科目での有効性はまだ検証していません。

## 必要な環境

- スキルを利用でき、PDF・画像の確認とローカルコマンドの実行ができるCodex環境。
- yomiyasuの公開指示・必要なファイルを取得できるネットワーク環境と、検査スクリプトを実行するPython環境。
- LaTeXをPDFへ組版する環境。付属の日本語テンプレートはLuaLaTeX、LuaTeX-ja、TikZなどを使用します。
- `latexmk`（推奨）と、PDFを画像化する`pdftoppm`などのツール。

このリポジトリには、Codexへの作業指示とテンプレートを収録しています。PDFを投入するだけで処理する独立した変換アプリではありません。必要なツールは利用環境側で用意してください。

## インストール

Codexの`skill-installer`が利用できる場合は、次のように依頼します。

```text
$skill-installer
cometscome/handwritten2pdf の
skills/handwritten-lecture-notes をインストールしてください。
```

手動で導入する場合は、[スキルのフォルダ](skills/handwritten-lecture-notes)を丸ごと、お使いのCodex環境のスキル保存先へ配置します。`SKILL.md`だけでなく、`references`と`assets`も含めてください。

## 日本語の推敲とyomiyasu

日本語教材の作成・改訂では、[yomiyasu（よみやす）](https://github.com/nanaism/yomiyasu)による推敲を必須工程とします。原本から説明を補った下書きを作った後で、意味・条件・専門用語を保ちながら、主述関係、指示語、文のつながり、不要な装飾などを点検します。

利用者がyomiyasuを別途インストールする必要はありません。本スキルの指示に従い、Codexが推敲時に[yomiyasuのSKILL.md](https://github.com/nanaism/yomiyasu/blob/main/skills/yomiyasu/SKILL.md)を自動で取得して読み、その手順を適用します。必要な参照文書や検査スクリプトは作業用の一時フォルダに取得して使用します。スキル保存先へのインストールや、本リポジトリへの同梱は行いません。

公開指示の取得や必須検査を実行できない場合は、理由と未完了の工程を報告し、教材は暫定版として扱います。

数式の正しさ、図との整合、原本との対応は別途確認します。文章の推敲だけで教材の内容が検証されたとは扱いません。

## 使い方

原本のPDF・画像をCodexから参照できる場所に置き、対象範囲と出力の希望を伝えます。

```text
$handwritten-lecture-notes
この手書きPDFの第1章に当たる部分を、学生向けの講義ノートにしてください。
原本の順序を基本に説明を補い、図はTikZで作成してください。
TeXとPDFを出力し、訂正・補足した箇所もまとめてください。
```

対象学生の学年・既習事項、逐語転記か説明を補う教材化か、既存教材との比較が必要かを指定すると、編集方針を合わせやすくなります。

## ファイル構成

```text
skills/handwritten-lecture-notes/
├── SKILL.md                          # スキル本体
├── agents/openai.yaml                # Codexでの表示情報
├── references/
│   ├── editorial-verification.md     # 原本照合・文章化・内容検証
│   ├── tikz-figures.md               # 作図と図の検証
│   └── latex-delivery.md             # ビルド・配布版・目視確認
└── assets/
    └── lecture-notes-ja.tex          # 日本語LuaLaTeXテンプレート
```

付属テンプレートには微分と接線の短い例があります。利用時は対象講義の本文と図に置き換えます。

## バージョン0.1での確認

- スキルの形式と内部リンクを検証しました。
- 日本語テンプレートをLuaLaTeXでコンパイルし、生成PDFを目視確認しました。
- 手書きの電磁気学講義ノートの冒頭部分を教材化し、TikZ図4点を含む4ページの試作教材を既存版と比較しました。

この試用は一つの事例であり、スキルの有無だけを比較した独立評価や、学生の理解度の測定は行っていません。原本PDFと講義固有の試作教材は、このリポジトリには含めていません。
上記の教材化試作はyomiyasuを必須工程にする前のものです。必須工程を含む一連の処理の再試験は未実施です。
